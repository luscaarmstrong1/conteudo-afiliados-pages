Política de privacidade - Achadinhos Conteúdo

Última atualização: 2026-07-21

Quem opera este site

Achadinhos é operado por Lucas Henrique Silva para organização interna e uso pessoal de conteúdo de afiliado.

Finalidade da automação

Ferramenta interna e de uso pessoal para organizar imagens, links de afiliado, campanhas e publicações orgânicas relacionadas a casa, cozinha, organização, decoração, gadgets, beleza e achadinhos.

Dados operacionais usados

Os dados tratados incluem imagens, títulos, descrições, links, categorias, logs técnicos, metadados de publicação, horários planejados, histórico de geração e palavras-chave necessárias para publicar páginas públicas e feeds RSS.

Credenciais e navegador

Esta modalidade não coleta senha do Pinterest, não captura cookies, não automatiza navegador, não usa scraping e não usa API do Pinterest. Também não armazena credenciais em páginas públicas.

Compartilhamento

Não vendemos, revendemos ou compartilhamos dados pessoais. Os links podem ser de afiliado e as imagens podem ser hospedadas no Cloudinary. As páginas públicas são publicadas via GitHub Pages.
